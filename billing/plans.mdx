One Superwhisper Pro license works on **all your devices** — unlimited Macs and Windows PCs, plus your iPhone and iPad. You never buy per platform.

## Free vs Pro

| Feature | Free | Pro |
|:--------|:----:|:---:|
| Voice dictation | ✓ | ✓ |
| Basic transcription | ✓ | ✓ |
| Cloud voice models | Limited | Unlimited |
| Local voice models | - | ✓ |
| Custom modes | - | ✓ |
| AI-powered modes (Super, Email, etc.) | - | ✓ |
| Custom vocabulary | - | ✓ |
| Speaker separation | - | ✓ |
| Priority support | - | ✓ |

<Note>
New users get 15 minutes of free access to all Pro features and can create 3 modes to try everything out.
</Note>

## Pricing

| Plan | Price | Best For |
|:-----|:------|:---------|
| Monthly | $8.49/month | Trying Pro features |
| Annual | $84.99/year | Regular users (save ~17%) |
| Lifetime | $249.99 once | Power users |

All plans include the same features on all platforms. The only difference is billing frequency.

## Where to buy

1. **Superwhisper website (recommended)** — buy at [superwhisper.com](https://superwhisper.com). Lower price, your license key is emailed directly, and we can help with any purchase issue.
2. **iOS App Store** — buy inside the iPhone/iPad app. Higher price due to Apple's fees. Your key is in the app under **Settings → Superwhisper Pro → Reveal License Key**; use it to [activate on Mac and Windows](/billing/activate).

<Warning>
We can't manage App Store billing, refunds, or subscriptions on our end. For App Store billing issues, contact [Apple Support](https://support.apple.com/billing).
</Warning>

## FAQ

### Do I need separate licenses for Mac, Windows, and iPhone?
No. One Pro license works on all platforms.

### Can I use my license on multiple computers?
Yes. There's no device limit for Mac and Windows computers.

### Do my custom modes sync between devices?
Modes and vocabulary are stored locally on each device. Cloud sync is planned.

### How do teams and companies buy?
See [Enterprise](/enterprise/getting-started) for seat-based licensing, SSO, and centralized deployment.
