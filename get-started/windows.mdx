Superwhisper runs natively on Windows 10 and 11, on x64 and ARM64. It's the same app and the same license as macOS; one purchase covers both platforms.

## Install

1. Download the installer from [superwhisper.com/windows](https://superwhisper.com/windows)
2. Run the installer and follow the prompts
3. Superwhisper starts and adds an icon to your **system tray**. Click it to open settings
4. Allow **microphone access** when Windows asks
5. Follow the setup wizard, then try your first dictation ([Quickstart](/get-started/quickstart))

<Info>
Bought the Mac version by mistake, or switching machines? Download the Windows installer and [enter the same key](/billing/activate).
</Info>

## Requirements

Superwhisper runs on Windows 10 and 11, on x64 and ARM64 processors. A GPU is not required.

- **Local voice models** depend on your hardware:
  - **Cohere Transcribe** and **Whisper Large v3 Turbo** use Vulkan when your GPU and drivers support it. Without Vulkan, they fall back to the CPU, which is much slower.
  - **Parakeet Multilanguage** runs through ONNX Runtime on x64 and ARM64 machines. It does not need Vulkan.
  - Windows ARM has no Vulkan support in Superwhisper. On ARM, Cohere Transcribe and Whisper Large v3 Turbo are not supported yet. Use Parakeet Multilanguage or a cloud model.
- **Cloud models** run on any machine. Use them when your hardware is too slow for local models, such as old integrated graphics or a virtual machine.

## Installation problems

### The app won't launch, or shows a `vkGetPhysicalDeviceFeatures2` or missing DLL error

You may see an error like `vkGetPhysicalDeviceFeatures2 could not be located`.

1. Update your graphics drivers from your GPU vendor (Intel, NVIDIA, or AMD)
2. Restart and launch Superwhisper again
3. If the app opens but local models are very slow or fail, your GPU may not support Vulkan. Pick Parakeet Multilanguage or a cloud model instead
4. If you're still stuck, email [support@superwhisper.com](mailto:support@superwhisper.com) with your Windows version and GPU model

## Where your files live

Superwhisper stores configuration, modes, and recordings in this app data folder. Recordings are in its `recordings` subfolder.

```
%LOCALAPPDATA%\com.superwhisper.app
```

Paste that path into the File Explorer address bar to open it. You can't change this location on Windows yet.

## Differences from macOS

Most features work the same. These aren't available on Windows yet:

- **Filesync**: syncing configuration across installations (in development)
- **Custom app folder location**: the default path above is always used
- **Hold Shift to Auto-Send**
- **Simulate Keypresses**
- **[Coding agent integrations](/get-started/coding-agents)** (Claude Code, OpenCode, Codex, Cursor, Pi, Grok, DeepSeek) and the [CLI](/get-started/cli)

Everything else works the same as on macOS, so the rest of these docs apply to both platforms. That includes modes and custom modes, vocabulary and replacements, local and cloud models, file transcription, [realtime transcription](/common-issues/realtime), system audio recording, and [speaker separation](/modes/speaker-separated-meetings).
