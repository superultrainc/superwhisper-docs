Advanced settings live in **Settings → Configuration → Advanced settings**. They control application behavior, performance, text delivery, and where Superwhisper stores its files.

## Application

<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/screens/mac/settings-application.png"
  alt="Superwhisper Application settings: Show in Dock, Start Recording on Menubar Click, Always close"
/>

### Show in Dock
Controls whether Superwhisper appears in your Dock.

### Start Recording on Menubar Click
Left-clicking the menu bar icon starts or stops recording. Right-click the icon to open the regular menu.

### Always close
Closes the recording window after every dictation, whether or not the paste succeeded. Your text stays on the clipboard for manual pasting.

## Voice model

<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/screens/mac/settings-voice-model.png"
  alt="Superwhisper Voice model active duration setting"
/>

**Voice model active duration** controls how long the voice model stays loaded in memory. Longer durations make the next dictation start faster but hold memory from other applications. Shorter durations free memory but add load time when a new dictation starts.

## App folder location

<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/screens/mac/settings-folder-location.png"
  alt="Superwhisper app folder location with Change folder button and Filesync toggle"
/>

Superwhisper keeps its files in the `~/superwhisper` folder in your home directory by default (older installs may still use `~/Documents/superwhisper`). The folder stores your history, custom modes, vocabulary, and text replacements. [Back it up](/get-started/backing-up-settings) to preserve your setup or move it to a new machine. Use **Change folder** to store it somewhere else.

<Note>
Superwhisper uses this folder actively during dictation, so keep it locally accessible on your device.
</Note>

### Filesync
Syncs your Superwhisper configuration files across all installations registered under the same license.

## Text input

<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/screens/mac/settings-text-input.png"
  alt="Superwhisper Text input settings: paste result, auto-send, clipboard behaviour, simulate keypresses"
/>

### Paste result text
Delivers your result by pasting at the cursor. If you turn it off, Superwhisper still saves results to your clipboard; paste them manually.

### Hold shift to auto-send after paste
Holding Shift when you finish a dictation simulates pressing Return. Useful for quick messages in chat applications.

### Clipboard Behaviour
By default, your result replaces whatever was on your clipboard. Set **Clipboard behaviour** to **Restore clipboard** to put your previous clipboard content back after pasting. **Restore clipboard delay** controls how long Superwhisper waits before restoring.

### Simulate keypresses
An alternative delivery method for applications that block direct pasting, such as secure fields. Superwhisper types the result as individual keystrokes instead.
