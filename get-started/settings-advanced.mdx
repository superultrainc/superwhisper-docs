Advanced settings control application behavior, performance, and where Superwhisper stores its files. This page explains each option.

## Recording window
<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/get-started/settings-advanced-006.png"
  alt="Superwhisper Recording Window Options"
/>

### Recording Window Enabled
Disable the recording window to dictate without anything on screen. Audio cues still signal when recording starts and when processing completes.

### Auto-Close Window
By default, with the recording window and paste result enabled, the window closes only after a successful paste. Enable this to close the window after every dictation regardless of paste status. Your text stays on the clipboard for manual pasting.

### Mini Recording Window
Use the mini recording window by default. You can switch between the mini and regular window anytime [through the interface](interface-rec-window).

### Always show Mini Recording Window
Keeps a small indicator on screen at all times. Hover over it to start recording, switch modes, or open the larger recording window.

### Show in Dock
Controls whether Superwhisper appears in your Dock.

### Start Recording on Menubar Click
Left-clicking the menu bar icon starts or stops recording. Right-click the icon to open the regular menu.

## Voice processing options
<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/get-started/settings-advanced-003.png"
  alt="Superwhisper Voice Processing Options"
/>

### Voice Model Active Duration
Controls how long the voice model stays loaded in memory. Longer durations make the next dictation start faster but hold memory from other applications. Shorter durations free memory but add load time when a new dictation starts.

### Dynamic Normalization
Normalizes and filters recordings to a consistent loudness. This keeps your voice clearly recognized despite changes in microphone distance or background noise.

## Folder location
<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/get-started/settings-advanced-004.png"
  alt="Superwhisper Folder Location"
/>

Superwhisper keeps its files in the `~/superwhisper` folder in your home directory by default (older installs may still use `~/Documents/superwhisper`). The folder stores your history, custom modes, vocabulary, and text replacements. [Back it up](backing-up-settings) to preserve your setup or move it to a new machine.

<Note>
Superwhisper uses this folder actively during dictation, so keep it locally accessible on your device.
</Note>

### Filesync
Syncs your Superwhisper configuration files across all installations registered under the same license.

## Text input controls
<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/get-started/settings-advanced-005.png"
  alt="Superwhisper Text Processing Options"
/>

### Paste Result Text
Works with the recording window settings to determine how results are delivered. If you disable both the recording window and paste result, Superwhisper still saves results to your clipboard; paste them manually since nothing shows on screen.

### Hold Shift to Auto-Send
Holding Shift when you finish a dictation simulates pressing Return. Useful for quick messages in chat applications.

### Restore Clipboard
By default, your result replaces whatever was on your clipboard. Turn this on to put your previous clipboard content back after pasting.

### Simulate Keypresses
An alternative delivery method for applications that block direct pasting, such as secure fields. Superwhisper types the result as individual keystrokes instead.
