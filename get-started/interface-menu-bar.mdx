The menu bar icon shows Superwhisper's status in real time and gives quick access to its main functions.

## Status indicator dot

A color-coded dot on the icon shows the current status:

<CardGroup cols={2}>
  <Card title="Yellow" icon="circle" horizontal>
    Model loading in progress
  </Card>
  <Card title="Red" icon="circle" horizontal>
    Active recording in progress
  </Card>
  <Card title="Blue" icon="circle" horizontal>
    Processing dictation
  </Card>
  <Card title="Green" icon="circle" horizontal>
    Processing completed
  </Card>
</CardGroup>

## Menu options

Click the icon to open the menu:

- Start or stop recording
- Transcribe external files
- Open [History](history)
- Open the main settings window
- Change the input device
- Change the active mode
- Check for updates
- Quit Superwhisper

## Quick recording

By default, clicking the icon opens the menu. Enable **Start Recording on Menubar Click** in [advanced settings](settings-advanced#application) to change this:

- Left click toggles recording
- Right click opens the full menu
