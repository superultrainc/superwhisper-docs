## Overview

Back up your Superwhisper settings to:

- **Move to a new computer**: transfer your whole setup
- **Use several devices**: keep the same modes and vocabulary everywhere
- **Protect your data**: guard against accidental deletion
- **Share a setup**: give a colleague your dictation configuration

---
## Configuration location

By default, Superwhisper saves all configuration files in the `~/superwhisper` folder in your home directory. To use a different location, change it in [advanced settings](/get-started/settings-advanced#app-folder-location).

<Note>
Installs from before the default changed may still use **~/Documents/superwhisper**. You can check your current location in Settings → Configuration → Advanced.
</Note>

The folder contains these subdirectories:

- **Models**: configuration files of custom models you've added
- **Modes**: all modes you've created or customized
- **Settings**: vocabulary lists and text replacements
- **Recordings**: your dictation history files

---
## Back up your settings

<Steps>
  <Step title="Locate the configuration folder">
    Open `~/superwhisper`, or your custom location if you changed the default.
  </Step>
  <Step title="Select what to back up">
    - Copy specific folders (Models, Modes, Settings) for a targeted backup
    - Skip the Recordings folder if you don't need dictation history
    - Copy the entire Superwhisper folder for a complete backup
  </Step>
  <Step title="Verify the backup">
    Check that the copy includes every folder you need.
  </Step>
</Steps>

---
## Restore settings on another device

Copy your backup folders into the Superwhisper configuration location on the new device, then restart the application.
