Superwhisper transcribes with **cloud models** (top accuracy the moment you install — nothing to download) or **local models** (everything stays on your device and works offline). Both are fast and accurate. Switch anytime, and every mode can use its own model.

## Cloud or local?

| | Cloud | Local |
|:--|:--|:--|
| Setup | None — works immediately | One-time download (75 MB – 3 GB) |
| Privacy | Audio processed on secure servers | Audio never leaves your device |
| Offline use | Requires internet | Works offline |
| Speed | Fast on any hardware | Fast on modern hardware |
| Best for | Most users, older machines | Privacy-sensitive work, travel |

**Start with the cloud model from onboarding — it gives great results on any machine.** Switch to a local model when you want audio to stay on your device or need to work offline.

## Browse and download models

Open **Settings → Models library** to browse every model, download local ones, and remove ones you no longer use.

## Picking a local model

All three are excellent — pick by what you value:

1. **Cohere Transcribe** (1.3 GB) — the most accurate local model. Our first pick.
2. **Parakeet Multilanguage** (494 MB) — built for speed; it flies through long recordings. Punctuation is lighter than the others.
3. **Ultra V3 Turbo** (1.6 GB) — fast and accurate, based on Whisper large-v3 turbo.

**Standard, Nano, and Fast** are free and small — great for quick notes. Local models shine on Apple Silicon Macs. On Windows they run on your GPU through Vulkan — see [Windows requirements](/get-started/windows#requirements).

## Set the model per mode

Each mode picks its own voice model (AI modes add a language model). Open **Modes**, select a mode, and change **Voice Model**.

<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/screens/mac/modes-editor.png"
  alt="Superwhisper mode editor showing the Voice Model and Language Model selectors"
/>

<Info>
Want to bring your own API keys (OpenAI, Anthropic, or any OpenAI-compatible provider)? Add them under **Settings → Configuration → Advanced settings → AI Models**. Pro already includes unlimited built-in cloud models, so this is optional.
</Info>
