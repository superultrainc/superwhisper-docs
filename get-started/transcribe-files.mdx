## Overview
Superwhisper can transcribe external audio and video files: meeting recordings, lectures, interviews, voice memos, and more. The file processes through your **currently active mode**, so the result uses that mode's voice model and AI formatting.

<Info>
**For the best results, use:**
- MP3 audio files
- MP4 video files
- Mono WAV files with a 16 kHz sample rate
</Info>

---
## 1. Transcribe from the menu bar

<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/get-started/transcribe-files-001.png"
  alt="Transcribe with Superwhisper Menu Bar"
/>

<Steps>
  <Step title="Verify the active mode">
    Make sure your preferred Superwhisper mode is active
  </Step>
  <Step title="Open the menu">
    Click Superwhisper's menu bar icon
  </Step>
  <Step title="Select Transcribe File">
    Choose **Transcribe File** from the menu
  </Step>
  <Step title="Choose the file">
    Browse and select the audio or video file to transcribe
  </Step>
</Steps>

---
## 2. Transcribe from Finder

<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/get-started/transcribe-files-002.png"
  alt="Transcribe Finder Files using Superwhisper"
/>

<Steps>
  <Step title="Locate the file">
    Find the audio file in Finder
  </Step>
  <Step title="Right-click it">
    Right-click the file to open the context menu
  </Step>
  <Step title="Open with Superwhisper">
    Select **Open With → Superwhisper**
    - If Superwhisper isn't listed, choose **Other** and select the application
  </Step>
</Steps>

---
## 3. Transcribe from the command line

You can also transcribe files from the terminal:
```bash
open /path/to/your/audiofile.mp3 -a superwhisper
```
