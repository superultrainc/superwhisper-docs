---
title: "Update error on macOS"
description: "Fix \"An error occurred while running the updater\" when updating Superwhisper on macOS. Download the latest version and replace the app."
---

## The error

**You click Install Update and see "Update Error! An error occurred while running the updater. Please try again later."** macOS didn't start the helper Superwhisper uses to install updates. This affects older versions of Superwhisper, 2.19.1 and earlier, on some Macs. Version 2.19.2 and later, including the current release, install updates correctly on these Macs, so you only need to get past this once.

## The fix: install the latest version yourself

1. Quit Superwhisper
2. Download the latest version from [superwhisper.com](https://superwhisper.com)
3. Drag the app into **Applications** and replace the old copy. Your history, modes, and settings are stored separately and stay intact
4. Open Superwhisper

<Note>
Restarting your Mac can also clear this, but downloading the latest version is the quickest fix.
</Note>

<Tip>
Current versions install updates automatically and remind you from the menu bar when one is waiting. Once you are on a current version, you should not see this error again. To manage updates yourself, see [Software and Model Updates](/enterprise/updates).
</Tip>

If the error comes back after you install the latest version, email [support@superwhisper.com](mailto:support@superwhisper.com) with your macOS version and your Superwhisper version (shown in the menu bar icon's menu).
