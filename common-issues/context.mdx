## Overview

Context awareness lets Superwhisper process your dictation with relevant information from your screen, which produces more accurate results.

---
### Types of context

Superwhisper can capture three types of context:

<CardGroup cols={3}>
  <Card title="Selected Text Context" icon="text-size">
    Text that is highlighted/selected in your active window when you begin recording.
  </Card>
  <Card title="Application Context" icon="window">
    Text from active input fields, names, and title from your active window.
  </Card>
  <Card title="Clipboard Context" icon="clipboard">
    Content that has been copied to your clipboard before or during dictation.
  </Card>
</CardGroup>

---
### Which modes capture context

- **Built-in modes**: most don't have context awareness enabled
- **Super Mode**: the only built-in mode with all three context types on by default
- **Custom modes**: can use any combination of context types

<Tip>
Enable only the context types a mode needs. Unnecessary context sends extra information to the AI and can hurt result quality.
</Tip>

---
### When each context is captured

Each context type is captured at a different point in the dictation:

<Steps>
  <Step title="Selected Text Context">
    Captured exactly when you start recording (when you toggle on dictation). The focus must remain on the application containing the selected text at this moment.
  </Step>
  <Step title="Clipboard Context">
    Captured either within three seconds before recording starts OR during dictation. The last item copied during this period will be used.
  </Step>
  <Step title="Application Context">
    Captured after voice processing is complete, between the transcription and AI processing steps. This means your active window at this point determines what context is captured.
  </Step>
</Steps>

---
## Context issues and solutions

### Selected text context not working
- **Focus**: keep focus on the application with the selected text when you start recording
- **Mode configuration**: verify you're using Super Mode or a custom mode with [selected text context enabled](/modes/custom#context-awareness)
- **Deep links**: when triggering recording via deep links from shell commands, use the `-g` flag to open in the background so focus stays on your target application

---
### Application context not working
- **Switching windows**: if you switch windows after dictating but before processing completes, you may capture the wrong context or none
- **Accessibility permission**: make sure Superwhisper is enabled in **System Settings → Privacy & Security → Accessibility**
- **Mode configuration**: verify the mode has application context enabled

---
### Clipboard context not working
- **Timing**: copy the content within three seconds before starting recording, or during dictation
- **Mode configuration**: verify the mode has clipboard context enabled
