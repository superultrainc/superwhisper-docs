---
title: "Modes not saving or disappearing"
description: "Fix modes that will not save, vanish after a restart, or fail to create. Check where the Superwhisper folder lives."
---

## Overview
If Superwhisper can't write to its folder, new modes fail to save. iCloud Documents syncing can move a folder in Documents and cause this. The fix is to point Superwhisper at a folder outside iCloud.

<Note>
Older installs kept the Superwhisper folder in `~/Documents`. The current default is `~/superwhisper` in your home directory.
</Note>

---
## Fix the folder location
Redirect Superwhisper to a folder outside iCloud:

<Steps>
  <Step title="Open Advanced settings">
    Open **Advanced settings** from the left sidebar in Superwhisper settings.
  </Step>
  
  <Step title="Change the folder location">
    Scroll to **App folder location** and click **Change folder...**.
      <img style={{ borderRadius: '0.5rem' }} src="/images/screens/mac/settings-folder-location.png" alt="Superwhisper Folder Location" />
  </Step>
  
  <Step title="Select a new folder location">
    In the file browser, choose your home folder or another location outside iCloud, and click **Open**.
  </Step>
  
  <Step title="Confirm the change">
    Click **Confirm** in the dialog to apply the change.
  </Step>
</Steps>

Superwhisper now uses the new location. Try saving a mode again.

## Modes missing on iPhone or another Mac

Modes and vocabulary don't sync between devices by default. On Macs, enable [Filesync](/get-started/settings-advanced#filesync) on each install under the same license to sync configuration. Windows and iOS sync aren't available yet: recreate your most-used modes there, or [back up and copy the Superwhisper folder](/get-started/backing-up-settings) between computers.
