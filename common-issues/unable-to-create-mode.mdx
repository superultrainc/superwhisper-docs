---
title: "Modes Not Saving or Disappearing"
description: "Fix Superwhisper modes that won't save, vanish after restart, or fail to create. Usually an iCloud folder move."
---

## Overview
When iCloud Documents syncing is enabled on your Mac, the Superwhisper folder may move to iCloud while the app still references the original location. This mismatch prevents Superwhisper from saving new modes and can cause other problems.

<Note>
This mainly affects older installs where the Superwhisper folder lived in ~/Documents. The current default is ~/superwhisper in your home directory, which iCloud Documents syncing doesn't touch.
</Note>

---
## Fix the folder location
Redirect Superwhisper to a folder outside iCloud:

<Steps>
  <Step title="Open the Configuration Tab">
    Access the Configuration section from the left sidebar menu in Superwhisper and go to "Advanced Settings."
  </Step>
  
  <Step title="Change Folder Location">
    Scroll down to find the "Change Folder" option and click it.
      <img style={{ borderRadius: '0.5rem' }} src="/images/screens/mac/settings-folder-location.png" alt="Superwhisper Folder Location" />
  </Step>
  
  <Step title="Select a New Folder Location">
    In the file browser that appears, navigate to your home folder (or another location outside iCloud) and click "Open".
  </Step>
  
  <Step title="Confirm the Change">
    Click "Confirm" in the dialog box to apply the folder location change.
  </Step>
</Steps>

Superwhisper now references the new location, and modes save normally again.

## Modes missing on iPhone or another Mac

Modes and vocabulary don't sync between devices by default. On Macs, enable [Filesync](/get-started/settings-advanced#filesync) on each install under the same license to sync configuration. Windows and iOS sync aren't available yet: recreate your most-used modes there, or [back up and copy the Superwhisper folder](/get-started/backing-up-settings) between computers.
