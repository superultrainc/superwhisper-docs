description: "Find the fix for your Superwhisper problem by its symptom. Topics include errors, crashes, pasting, shortcuts, microphone, and performance."

Find your problem below by its symptom. Superwhisper saves every dictation as you speak, so your recording is safe in [History](/get-started/history) and can be reprocessed after the fix.

<Tip>
Turn on **Error logging** in **Settings → Configuration** before reproducing a problem. See [Logs & reporting](/common-issues/diagnostics).
</Tip>

## Error messages

<CardGroup cols={2}>
  <Card title="&quot;No voice found&quot; or stuck processing" href="/common-issues/no-voice-found">
    Fix recordings with no detectable speech, or processing that never ends.
  </Card>
  <Card title="AI formatting didn't run and pasted raw text" href="/common-issues/llm-processing-error">
    You got the raw transcription because the AI step failed. Covers connection, model, and API-key checks.
  </Card>
  <Card title="App won't launch or install" href="/common-issues/app-wont-launch">
    Fix Windows DLL and Vulkan errors, installer problems, and macOS launch failures.
  </Card>
  <Card title="Superwhisper crashes or quits unexpectedly" href="/common-issues/crashes">
    Find out whether the model, the mode, or the machine causes the crash.
  </Card>
</CardGroup>

## Wrong output

<CardGroup cols={2}>
  <Card title="Transcribed in English instead of my language" href="/common-issues/language-detection">
    Set a fixed language or add a hint when Automatic picks English.
  </Card>
  <Card title="Gibberish, repeated, or made-up text" href="/common-issues/hallucinations">
    Find the stage that adds words you never said, and reduce it.
  </Card>
  <Card title="AI answers instead of transcribing" href="/modes/custom#prompting-tips">
    A mode's prompt causes this. Prompting tips help you fix it.
  </Card>
  <Card title="Text not pasting, pasting twice, or pasting old text" href="/common-issues/pasting-issues">
    Fix paste problems with permissions, clipboard content, and simulate keypresses.
  </Card>
</CardGroup>

## Input and controls

<CardGroup cols={2}>
  <Card title="Shortcuts not working or misfiring" href="/common-issues/shortcuts-not-working">
    Check key conflicts, global and per-mode shortcuts, and push to talk.
  </Card>
  <Card title="Wrong microphone or system audio" href="/common-issues/microphone-and-system-audio">
    Switch inputs, handle Bluetooth headsets, and fix empty meeting recordings.
  </Card>
  <Card title="Modes not saving or disappearing" href="/common-issues/unable-to-create-mode">

  </Card>
  <Card title="Slow dictations or heavy memory use" href="/common-issues/performance-tips">
    Adjust model choice and voice model load time, then find the slow step.
  </Card>
</CardGroup>
