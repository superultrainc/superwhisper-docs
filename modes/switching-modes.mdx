## Overview
There are four ways to switch modes. Pick the one that fits how you work: a shortcut for switching mid-dictation, the menu bar for occasional changes, auto-activation for hands-off switching per app, and deep links for automation tools.

---
## Keyboard shortcut
A quick way to switch modes just before dictating, while the recording window is open.
<img
style={{ borderRadius: '0.5rem' }}
src="/images/modes/modes-switching-001.png"
alt="Customizing the change mode keyboard shortcut"
/>

1. Trigger dictation to open the recording window
2. Press your configured "Change Mode" keyboard shortcut
3. Hold the modifier key(s) and tap the other key repeatedly to cycle through modes
4. Release when you reach your desired mode

<Note>The active mode is visible only in the large recording window view.</Note>

---
## Menu bar
Change modes anytime from the menu bar.
<img
style={{ borderRadius: '0.5rem' }}
src="/images/modes/modes-switching-002.png"
alt="Menu bar dropdown showing mode selection options"
/>

1. Click the Superwhisper menu bar icon
2. Select a new mode from the "Select Mode" submenu

## Deep links
Deep links let automation tools switch modes and start recording. Superwhisper supports two:
```
superwhisper://mode?key=YOUR_MODE_KEY
superwhisper://record
```
<img
style={{ borderRadius: '0.5rem' }}
src="/images/modes/modes-switching-005.png"
alt="Where to find the key of each mode"
/>

**To find a mode's key:**
1. Open `~/superwhisper/modes` (or `~/Documents/superwhisper/modes` on older installs)
2. Quick Look the JSON files and match your mode by its `name` value
3. Copy the `key` value into your deep link

<Tip>Combine both deep links in an automation tool to switch modes and start recording in one action. Here's a [sample shortcut](https://www.icloud.com/shortcuts/a925e259d5e84806a700c2a58d4853a4) to start from.</Tip>
